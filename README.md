# Safan Sulfikar

I build web applications and Windows desktop tools. My work focuses on clean interfaces, local-first performance, and Bluetooth Low Energy integrations.

## Selected projects

- **[Lightsout](https://github.com/Depth118/Lightsout).** An F1 calendar web app with live session countdowns and localized timezone conversion. Built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.
- **[Spigen Audio Controller](https://github.com/Depth118/Spigen-audio-ctrl).** A Windows companion app for Spigen SA-HP P10 headphones. Communicates over Bluetooth Low Energy to switch ANC modes, tune a 10-band hardware DSP equalizer, and remap physical buttons. Written in C#.
- **[AniXP](https://github.com/Depth118/AniXP).** A Windows XP desktop environment in the browser with window management, a start menu, and search through the AniList API. Written in JavaScript and CSS.
- **[Checkered](https://github.com/Depth118/Checkered).** An in-browser tool that removes backgrounds from images locally on the client. Written in TypeScript.

## Stack

- **Languages:** TypeScript, JavaScript, C#, HTML, CSS
- **Frameworks and UI:** React, Next.js, Tailwind CSS, shadcn/ui
- **Systems and tools:** Windows API, Bluetooth Low Energy, Node.js, Git
